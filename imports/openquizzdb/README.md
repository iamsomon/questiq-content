# OpenQuizzDB: готовая структура викторин для отбора

Бесплатный источник с четырьмя вариантами и пояснениями. Сохранены **3 291 английская запись из 110 тематических пакетов**, авторская атрибуция и исходная лицензия CC BY-SA 4.0. Это англоязычные исходники для адаптации; в приложение они не включены. RU не добавлен, редакционные одобрения не выдавались.

Источник: **OpenQuizzDB**, авторы указаны в `sourceAuthor` каждой строки; зеркало **Zeuh/OpenQuizzDB**, commit `a16819964d171e40e6652368fc562f3bd27d0c5b`. [Репозиторий зеркала](https://github.com/Zeuh/OpenQuizzDB), [издатель](https://www.openquizzdb.org/), [условия издателя](https://www.openquizzdb.org/licence/). Данные и преобразованная коллекция распространяются по [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/); полный текст — [LICENSE-CC-BY-SA-4.0.txt](LICENSE-CC-BY-SA-4.0.txt). Одобрение Questiq авторами не подразумевается.

Изменения: извлечение английских записей из двух структур JSON, проверка четырёх различных вариантов и совпадения исходного ответа, исключение структурных ошибок, перевод в JSONL, добавление происхождения и списка незавершённых проверок. Тексты вопроса, пояснения и вариантов не исправлялись и не переводились. Медиа и другие языки не переносились. Лицензия этой адаптации не распространяется автоматически на приложение или отдельно написанные вопросы.

## Результат проверки

- 290 исходных JSON-файлов просмотрены программой, 26 с ошибками JSON/UTF-8 пропущены без попытки угадать исправление.
- В прочитанных файлах найдено 3 300 EN-записей; девять исключены структурной проверкой.
- В принятых строках 3 285 различных нормализованных формулировок: шесть точных повторов остаются отмеченными числом в отчёте. Содержательные и межбазовые повторы ещё не исключены.
- Правильный индекс — утверждение исходника, а не фактчек. Встречаются ошибки перевода: например, ответ `Erections` в вопросе о метках территории рыси и `Epistle` вместо типа бойца. Такие строки не разрешено автоматически переносить в игру.
- Ещё нужны RU, проверка основного факта и трёх неверных вариантов, редактура пояснения и EN, сопоставление с нашими категориями, проверка смысловых повторов и редакционное принятие.

Детали исключений, хеши файлов и тематический состав — [report.json](report.json). Архив закреплён по SHA-256; код издателя не выполняется, архив не распаковывается в произвольные пути. Объём исходного архива — около 83 МБ, мобильное приложение его не скачивает.

```sh
python3 tools/import_openquizzdb.py --cache /tmp/questiq-openquizzdb
python3 -m unittest discover -s tests
```

Все строки имеют статус `unverified_source_candidate`. Число импортированных записей не заменяет счётчик готовых игровых вопросов. Приложение получает только проверенные `dist`-пакеты. Новая игровая партия в этом PR написана отдельно по первичным фактическим источникам; исходные тексты и дистракторы этой коллекции туда не копировались.
