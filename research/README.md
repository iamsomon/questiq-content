# Исследование источников и очередь отбора

23 октября 2026. Эта папка не входит в `dist` и не загружается приложением.

## Сравнение баз

- [Open Trivia DB](https://opentdb.com/api_config.php): общественная база, CC BY-SA 4.0. Нужны атрибуция и соблюдение условий для адаптаций; API выдаёт ограниченные порции и не заменяет проверку факта.
- [OpenQuizzDB](https://www.openquizzdb.org/licence/): CC BY-SA 4.0, разрешены коммерческие адаптации при выполнении условий. Готового проверенного русского набора для нашего формата не установлено. Массовая загрузка не выполнялась.
- [The Trivia API](https://the-trivia-api.com/docs/): бесплатные данные с ограничением NonCommercial; для приложения с рекламой этот бесплатный вариант не выбран.
- [Wikidata](https://www.wikidata.org/wiki/Wikidata:Licensing): структурированные данные CC0. Подходит для поиска фактов и сущностей; само наличие утверждения в Wikidata не заменяет первичный источник.
- [OpenTriviaQA](https://github.com/uberspot/OpenTriviaQA): историческая общественная коллекция под CC BY-SA 4.0. Используется только как очередь тем и кандидатов. Встречаются старые, неоднозначные и не подтверждённые первичным источником ответы.

## 10 000 кандидатов — не 10 000 готовых вопросов

`candidates/open-trivia-qa.jsonl` содержит ровно 10 000 записей с уникальными нормализованными формулировками EN, четырьмя различными вариантами и совпадением ответа с одним из вариантов. Это только структурные проверки: содержательные повторы и неверные ответы ещё возможны.

Источник зафиксирован по commit `dcc1cdf36c2985ed5c849d1f2265c5041ffcdfb9`. В каждой записи есть URL, номер строки, авторская атрибуция, лицензия, статус `unverified_source_candidate` и список недостающих этапов. Хеши скачанных исходников, исходные категории и хеш очереди — в `.report.json`. Исходные категории этой базы не являются нашими 50 категориями. Правильный индекс — утверждение исходной базы, а не наше подтверждение.

Атрибуция: **OpenTriviaQA contributors / uberspot**, https://github.com/uberspot/OpenTriviaQA. Исходные тексты и эта адаптация очереди распространяются по **CC BY-SA 4.0**: https://creativecommons.org/licenses/by-sa/4.0/. Текст лицензии — `licenses/OpenTriviaQA-CC-BY-SA-4.0.txt`. Изменения: разбор текстового формата, декодирование HTML/кодировок, фильтрация, удаление совпадающих формулировок, выборка по исходным категориям и добавление происхождения. Одобрение авторами исходной коллекции не подразумевается. Эта лицензия не применяется автоматически к коду мобильного приложения или независимо написанным вопросам.

Воспроизведение без ключей:

```sh
python3 tools/collect_candidates.py --cache /tmp/questiq-open-trivia-cache
```

После отбора: проверить именно факт и все дистракторы по первичному источнику, написать объяснение, подготовить RU/EN, назначить стабильную категорию и сложность, проверить смысловые повторы. Затем обычные `drafts → reviews → questions`, без автоматического approval. Перевод/адаптация чужого вопроса сохраняет лицензию и атрибуцию; перед включением таких переводов в приложение нужен явный учёт в данных и разделе лицензий. Сейчас все новые игровые вопросы написаны отдельно; записи этой очереди туда не переносились.

План — `catalog/expansion-plan.json`: 50 × 200, в каждой категории 80 easy / 80 medium / 40 hard, пять тематических квот по 40. Кандидаты не могут закрыть этот счётчик.
