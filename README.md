# Questiq Content

Публичный репозиторий двуязычных вопросов Questiq. Приложение и его ключи здесь не хранятся.

23 октября 2026: **190 игровых вопросов RU/EN в 18 категориях**. Проверка агентом, человеческое редакционное одобрение не заявляется. Цель 10 000 / 50 ещё не достигнута: осталось 9 810 вопросов. В `research/` отдельно лежат 10 000 англоязычных кандидатов для отбора; они не включены в игровой счётчик и не доставляются приложению. План тематического баланса — [catalog/expansion-plan.json](catalog/expansion-plan.json), происхождение и лицензии материалов — [research/README.md](research/README.md).

Обязательные правила: [CONTENT_RULES.md](CONTENT_RULES.md). Категории: [catalog/categories.json](catalog/categories.json).

- `drafts/` — неподготовленные к выпуску вопросы. Приложение их не загружает.
- `questions/` — вопросы, прошедшие предметную и языковую проверку.
- `reviews/` — привязанные к хешу записи проверки и источников.
- `dist/manifest.json` и `dist/packs/` — воспроизводимая сборка одобренного контента.
- `tools/content.py` — проверка, отчёт и сборка без облачных ключей.

```sh
python3 tools/content.py validate
python3 tools/content.py report
python3 tools/content.py build --base-url https://raw.githubusercontent.com/iamsomon/questiq-content/main/dist
python3 -m unittest discover -s tests
python3 tools/check_links.py
```

Изменения идут через ветку и Pull Request. Публикация требует предметной и языковой проверки; простое прохождение CI не подтверждает истинность факта. Сначала исправляют вопрос и повышают `revision`, затем пересобирают `dist/`. Отозванные ID сохраняются в `revoked.json` навсегда.

В приложении есть встроенный набор для первого запуска без сети. Обновления устанавливаются атомарно после проверки хешей; однажды загруженные вопросы доступны без сети. GitHub raw используется для стартовой поставки небольших текстовых пакетов, не считается безлимитной коммерческой CDN. Провайдер заменяется без изменения формата контента.
