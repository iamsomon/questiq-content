# Пополнение каталога, 14 ноября 2026

Добавлено 120 новых вопросов с русским и английским текстом. Страны и физика получили по 20, Олимпиады и мультфильмы по 40. В каждом из этих пакетов теперь 50 вопросов.

Для стран сверено положение каждой страны в географической иерархии [ООН M49](https://unstats.un.org/unsd/methodology/m49/). Для физики использованы таблицы 2 и 3 [справочника NIST по СИ](https://www.nist.gov/pml/special-publication-811/nist-guide-si-chapter-4-two-classes-si-units-and-si-prefixes). Вопросы об Олимпиадах основаны на образовательном справочнике и статистике медалей МОК. Вопросы о персонажах основаны на материалах Pixar и Disney о соответствующих фильмах. Точные разделы, URL и привязка к тексту вопроса записаны в `reviews/`.

Вопросы, варианты и объяснения написаны для Questiq. Факты и обе локали прошли отдельные проходы проверки агентом Codex. Хеши принятых формулировок закреплены в `authoring/nov14-first-batch.reviewed-selection.json`. Человеческое редакционное одобрение для этой партии не заявляется.

Пакеты по-прежнему используют схему 1 и 50 прежних идентификаторов тем. Все 1 520 прежних вопросов и их ревизии сохранены. В активном манифесте заменены четыре пакета. Все файлы из предыдущего манифеста доступны по прежним URL для клиентов, начавших обновление до публикации новой партии.
