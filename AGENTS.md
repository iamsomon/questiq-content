# Работа с Questiq Content

Прочитайте CONTENT_RULES.md полностью до изменения вопросов. Никогда не публикуйте черновики или невычитанные переводы как одобренные. Не создавайте ложные записи предметной/языковой проверки. Не меняйте стабильные ID и опубликованные ревизии задним числом. В репозитории допустимы только контент, схемы, редакционные правила и инструменты проверок. Нет сертификатов, Firebase plist, SSH-ключей, токенов и кода приложения.

Перед завершением: tools/content.py validate, tools/content.py report, тесты, воспроизводимая сборка и проверка diff. Укажите точное количество вопросов и категорий, не называйте доступность ссылки проверкой фактов. Публикация только через PR после необходимых проверок.
